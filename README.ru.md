# planar-echo

**Русский** · [\[English\]](README.md)

planar-echo - независимая предварительная версия с открытым исходным кодом для
локальной конвертации и исследования данных PST:EE. Текущий продукт - конвейер
конвертации и браузерный верстак. Мультиплеерный модульный рантайм строится
заново и сейчас недоступен.

Это активно разрабатываемая предварительная версия, которую нужно собирать из исходного кода, а не законченная игра или полноценная замена оригиналу. **Planescape: Torment: Enhanced Edition (PST:EE) - единственный текущий и эталонный профиль.** Для других игр на Infinity Engine нужны отдельные адаптеры; сейчас они не поддерживаются.

## Доступно сейчас

- Локальная конвертация легально приобретённой PST:EE с помощью Prism и WeiDU в данные Ghost, сгенерированные модули и ресурсы для браузера.
- Поиск и просмотр конвертированных ресурсов в браузерной рабочей среде, инспекторы игровых структур и медиафайлов, исследование ветвей диалогов.
- Явный статус перестройки на [`/play`](http://localhost:3000/play) и [`/mods`](http://localhost:3000/mods); сейчас эти страницы не запускают игру и не управляют модами.
- Исходные файлы игры и результат конвертации остаются на вашем компьютере; planar-echo не загружает их в сеть.

## Текущие ограничения

- Полное соответствие поведению ванильной игры и полная играбельность ещё не достигнуты.
- Мультиплеера пока нет.
- Play, daemon и композиция модов недоступны во время перестройки рантайма с чистого листа.
- Готовых установщиков нет; предварительную версию нужно собирать из исходного кода.
- В репозитории есть Docker-файлы для разработки, но Docker сейчас не является поддерживаемым способом запуска для игрока.
- PST:EE - единственный игровой профиль. Другие игры на Infinity Engine пока не поддерживаются.

## Направление развития

Это цели, а не описание возможностей текущей сборки:

- Сервер-авторитетные мультиплеерные сессии: один daemon и один замороженный точный lock набора модов.
- Определяемые модами версионированные таблицы протоколов, ресурсы и атомарные транзакции вместо фиксированных игровых сущностей в core.
- Заменяемые команды, системы, capabilities, представление и игровая политика без изменений kernel, daemon, gateway и базового Shell.
- Локально установленные клиентский код и игровые артефакты: удалённый сервер не раздаёт исполняемые bundles и оригинальный игровой контент.
- Постоянный мультиплеерный conformance-набор модов, затем проверочный IE-сценарий от Морга до Сигила.
- Дополнительные профили Infinity Engine через явные адаптеры.
- Готовые пакеты, когда проект будет к ним готов.

## Требования

- **Платформа:** Windows - основная среда разработки и запуска для игроков. Linux и macOS поддерживаются по мере возможности и считаются экспериментальными.
- Легально приобретённая PST:EE с файлом `CHITIN.KEY`.
- Рекомендуется [Node.js 24 LTS](https://nodejs.org/).
- Corepack и закреплённая в репозитории версия Yarn 4.
- [WeiDU](https://github.com/WeiDU/weidu): укажите локальный исполняемый файл или воспользуйтесь загрузчиком на экране конвертации.
- Современный браузер и достаточно места на локальном диске для зависимостей, кеша конвертации и результата Ghost.
- Git, если вы получаете исходный код из репозитория.

## Быстрый запуск из исходного кода

В корне репозитория выполните:

```bash
corepack enable
yarn
yarn build
yarn start
```

Откройте интерфейс по адресу [http://localhost:3000](http://localhost:3000). Локальная серверная часть работает на [http://localhost:3003](http://localhost:3003).

1. Откройте **Convert**. Выберите PST:EE и язык игры, укажите исполняемый файл WeiDU и игровой `CHITIN.KEY`, затем выберите пустой каталог для результата.
2. Подтвердите, что используете легально полученную копию, и запустите конвертацию. Не останавливайте процесс, пока интерфейс не сообщит о завершении.
3. Если пути не определяются, откройте **Settings** и проверьте адрес серверной части и каталог результата Ghost.
4. Используйте **Workbench** для просмотра ресурсов и диалогов. **Play** и **Mods** сейчас показывают только статус перестройки рантайма.

Docker сейчас не является поддерживаемой альтернативой этому способу запуска для игрока.

## Моды и доверие

Целевой рантайм исполняет JavaScript модов без песочницы: серверный код
получит права Node.js-процесса daemon, а клиентский - права Shell в браузере.
**Устанавливайте моды только из доверенных источников.** Версии, подписи и хеши
могут подтвердить идентичность артефактов, но не сделать их безопасными. В
Milestone 0 исполняемых runtime-модов нет.

Распространяемые моды для planar-echo должны использовать совместимые с GPL условия лицензирования и сохранять применимые уведомления о сторонних материалах.
